Overview

Yours, Truly is a full-stack wellness journaling web application designed for college students. It provides a private, structured space to track daily emotions, sleep, stress levels, and personal reflections using a rose/thorn/bud journaling framework — with secure authentication and a mood-based entry retrieval system.

How might we create a digital space that encourages daily reflection and emotional awareness for college students — as intimate and personal as a physical journal, but with the recall and insight of a database?
Python Flask MySQL Bcrypt Jinja2 HTML + CSS REST API

Motivation

College is a time of intense emotional flux — academic pressure, social transitions, and identity formation all happening simultaneously. Many students want to journal for mental wellness but struggle with blank-page paralysis. Physical journals can't be searched or queried. And existing digital options feel clinical, not personal.

I wanted to build something that felt like opening a real notebook — warm, inviting, and handwritten — but with the power of a database underneath: structured prompts, mood tracking, calendar retrieval, and secure multi-user accounts.

Core Features

📝
Daily Journal Entries

Structured prompts — rose (highlight), thorn (challenge), bud (something to look forward to) — plus sleep hours, primary mood, and stress level (1–10).

🔐
Secure Authentication

User registration and login with bcrypt password hashing and salting. Session-based access control ensures entries are private.

📅
Calendar & Mood Filter

Browse past entries by date or filter all entries by emotion — see every "Happy" day or every "Sad" day at a glance.

👤
User Profiles

Editable profile with class standing, major, residence hall, and profile picture upload with file-type validation.

✏️
Full CRUD Operations

Create, read, update, and delete journal entries. Auto-detects whether to insert a new entry or update an existing one for that date.

🎨
Journal Aesthetic

Notebook paper texture, binder rings, handwriting-style fonts, and a warm pink palette — the feeling of a physical journal in the browser.

Design & UI

The visual design intentionally evokes a physical wellness journal — ruled paper textures, binder ring imagery, handwriting fonts (Noteworthy, Brush Script MT), and a warm pink color palette. The goal was to make opening the app feel like opening your personal notebook.

Technical Architecture

A classic MVC pattern — Flask handles routing and rendering, a command module abstracts all database operations, and Jinja2 templates provide the view layer. The app uses session-based auth with bcrypt hashing.

Security & Privacy

Since journal entries are deeply personal, security was a primary concern throughout development.

🔑
Bcrypt Password Hashing

All passwords are hashed with bcrypt + salt before storage. Plaintext passwords never touch the database.

🛡️
Session-Based Access Control

Every protected route verifies the user session — unauthorized access redirects to home with an error message.

📎
Secure File Upload

Profile picture uploads are validated for allowed file types (png, jpg, gif), sanitized with secure_filename, and size-limited to 3MB.

🔒
Input Parameterization

All SQL queries use parameterized statements to prevent SQL injection attacks.

Implementation Details

Backend
Flask + Command Module

Clean separation between routing (app.py) and database operations (command.py). The command module provides a reusable API for all CRUD operations on both accounts and entries tables.

Auth Flow
Register → Hash → Session

Registration checks email uniqueness, hashes password with bcrypt + salt, inserts the account, then sets the session. Login verifies by re-hashing input against stored hash.

Entry Logic
Smart Insert/Update

On save, the app first attempts an INSERT. If the composite key (email + date) already exists, it catches the duplicate-key exception and performs an UPDATE instead — one button handles both cases.

Mood Query
Emotion-Based Retrieval

The calendar view allows filtering all entries by one of six emotions (Anger, Fear, Disgust, Happy, Sad, Surprise), surfacing patterns in emotional history over time.

Outcome & Reflection

Yours, Truly demonstrated how a thoughtful interface design can make a database-backed application feel personal and intimate — and how the right data model (composite keys, emotion tagging) can turn a simple CRUD app into a meaningful self-reflection tool.

This was my first full-stack web application from scratch — handling authentication, database design, file uploads, and a complete CRUD lifecycle. The project solidified my understanding of relational data modeling, server-side rendering, and security best practices (hashing, parameterized queries, file validation).

Most importantly, it taught me that the best software feels invisible — the journal aesthetic makes users forget they're interacting with a Flask app backed by MySQL. That's the goal.
